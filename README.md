# Útěk z ostrova
Textová dobrodružná hra postavená na frameworku Flask.

## O hře
Hrdina se probudil na soukromém ostrově a musí najít cestu ven. Cílem je získat klíče od člunu a uniknout.

## Ovládání
- Používej tlačítka pro pohyb (Dopředu, Dozadu, Doleva, Doprava).
- Sebrané předměty najdeš v batohu (otevřeš tlačítkem "Otevřít batoh").
- V batohu můžeš lektvary použít pro léčení nebo předměty vyhodit na zem.

## Instalace
1. Nainstaluj Flask: `pip install flask`
2. Spusť aplikaci: `python app.py`
3. Otevři prohlížeč na: `http://127.0.0.1:5000`

## Seznam knihoven
- Flask (verze 3.0+)
